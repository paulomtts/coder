# Design Backlog

Deferred decisions and future work from design sessions.

## Persona model switching (deferred from pygents-loop-rewire)

**Decision**: Personas change prompt overlay and tool filtering only — no model switching.

**Context**: The original pi-mono spec assigns model hints per persona (e.g., scout uses fast/cheap, planner/worker/reviewer use mid-tier). The original coder spec also included this. However, the current coder implementation has no model switching, and adding it couples persona definitions to provider-specific model names.

**Future work**: Add an optional `model` field to persona definitions that swaps `toolkit.main_model_config` on role switch. Requires deciding how model names are configured (env vars, config file, per-persona overrides).
